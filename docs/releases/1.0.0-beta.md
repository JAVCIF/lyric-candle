## English

**Lyric Candle 1.0 beta: a cleaner foundation and lyrics-only alpha export.**

- **Export only the lyrics with alpha.** *Design → Base video and export → Export as → ProRes 4444 · lyrics only with alpha* writes a ProRes 4444 `.mov` (`yuva444p10le`) with just the lyrics over a transparent background and no audio, even when the project uses a gradient, image or video background. Overlay it in Vegas, Premiere, DaVinci or another editor; enable *Use base video resolution and FPS* to match the source exactly.
- **Python 3.10–3.14.** PySide6 now accepts `>=6.8,<6.11`, so Python 3.14 installs (it needs PySide6 6.10). The suite passed on Python 3.14 + PySide6 6.10.3, 3.13 + 6.8.3 and 3.10 + 6.8.3.
- **Maintainability.** The 2,600-line main window is split into modules by responsibility (playback, marking, phrases, syllables, keyframes, design, history, project files, export). Behaviour is unchanged: the whole existing suite runs unmodified against the new structure.
- **Tidier repository.** Historical change notes live in `docs/releases/`, the Spanish user guide, verification and technical notes in `docs/`, and the Windows source launchers in `scripts\windows\` (run `scripts\windows\INSTALAR.bat`, then `INICIAR.bat`). The packaged app is unaffected.
- **Quality gates.** `pyproject.toml` declares the project and its Ruff configuration; Ruff runs in CI and gates releases. CI tests Python 3.12 on Linux and Windows, Python 3.14 and the oldest supported pair (Python 3.10 + PySide6 6.8.3).
- Settings, autosaves and projects from 0.2.x keep working; the data folder name is unchanged.

### Windows x64 downloads

- **Portable ZIP:** extract the entire archive and run `LyricCandle/LyricCandle.exe`. Keep `_internal` alongside the executable. Settings live in its `data` folder. Python is not required.
- **Setup EXE:** installs for your Windows user, with English/Spanish setup, Start menu shortcut, optional desktop shortcut and an uninstaller. Settings use your application data folder; uninstalling does not delete projects or user settings. Python is not required.
- `.sha256` files let you verify each download with `Get-FileHash -Algorithm SHA256 <file>`.

Windows 10/11 x64. These builds are unsigned, so Windows may show an unknown-publisher notice. External `ffmpeg.exe` and `ffprobe.exe` remain necessary for export, waveforms and video probing (ProRes needs the `prores_ks` encoder, present in common builds); place them in `tools` beside the EXE or add them to PATH. They are not included. This is a beta; sung-lyric recognition and automatic vocal alignment are not implemented.

All operating-system test jobs and the Ruff check must pass before release. Package checks launch the extracted portable app, install silently, launch the installed app and uninstall it. Audible playback and all hardware/codec combinations require testing on your own machine.

## Español

**Lyric Candle 1.0 beta: una base más limpia y exportación de solo la letra con alfa.**

- **Exportar solo la letra con alfa.** *Diseño → Video base y exportación → Exportar como → ProRes 4444 · solo letra con alfa* crea un `.mov` ProRes 4444 (`yuva444p10le`) con solo la letra sobre fondo transparente y sin audio, aunque el proyecto use degradado, imagen o video de fondo. Superponlo en Vegas, Premiere, DaVinci u otro editor; activa *Usar resolución y FPS del video base* para que coincida exactamente con el original.
- **Python 3.10–3.14.** PySide6 acepta ahora `>=6.8,<6.11`, así que Python 3.14 se instala (necesita PySide6 6.10). La suite pasó en Python 3.14 + PySide6 6.10.3, 3.13 + 6.8.3 y 3.10 + 6.8.3.
- **Mantenimiento.** La ventana principal de 2.600 líneas se divide en módulos por responsabilidad (reproducción, marcado, frases, sílabas, keyframes, diseño, historial, archivos de proyecto y exportación). El comportamiento no cambia: la suite existente corre sin modificaciones sobre la nueva estructura.
- **Repositorio ordenado.** Las notas históricas están en `docs/releases/`, la guía de uso en español, la verificación y las notas técnicas en `docs/`, y los lanzadores de Windows del código fuente en `scripts\windows\` (ejecuta `scripts\windows\INSTALAR.bat` y luego `INICIAR.bat`). La app empaquetada no cambia.
- **Controles de calidad.** `pyproject.toml` declara el proyecto y la configuración de Ruff; Ruff corre en CI y bloquea los releases. CI prueba Python 3.12 en Linux y Windows, Python 3.14 y la pareja más antigua soportada (Python 3.10 + PySide6 6.8.3).
- Los ajustes, autoguardados y proyectos de la 0.2.x siguen funcionando; la carpeta de datos no cambia de nombre.

### Descargas para Windows x64

- **ZIP portable:** extrae todo y abre `LyricCandle/LyricCandle.exe`. Conserva `_internal` junto al ejecutable. Los ajustes quedan en su carpeta `data`. No necesitas Python.
- **EXE instalador:** instala para tu usuario, incluye español/inglés, acceso en Inicio, acceso opcional en escritorio y desinstalador. Los ajustes usan la carpeta de datos del usuario; desinstalar no elimina proyectos ni ajustes. No necesitas Python.
- Los archivos `.sha256` permiten comprobar cada descarga con `Get-FileHash -Algorithm SHA256 <archivo>`.

Windows 10/11 x64. Los compilados no están firmados y Windows puede mostrar un aviso de editor desconocido. Para exportar, generar la onda y analizar video necesitas `ffmpeg.exe` y `ffprobe.exe` externos (ProRes necesita el codificador `prores_ks`, presente en las compilaciones habituales): ponlos en `tools` junto al EXE o agrégalos al PATH. No vienen incluidos. Es una beta; aún no reconoce letras cantadas ni alinea voces automáticamente.

La publicación exige que pasen las pruebas en todos los sistemas y la revisión de Ruff. La comprobación de paquetes abre el portable extraído, instala en silencio, abre la aplicación instalada y la desinstala. La reproducción audible y todas las combinaciones de hardware/códecs deben probarse en tu equipo.
