## English

**Hotfix: marking phrase boundaries with Zoom line now edits the selected phrase.**

- With Zoom line enabled, Start mark (Ctrl+M) changes only the selected phrase's start; End mark (Ctrl+F) changes only its end. Neither advances to another row or closes a different phrase.
- Seeking or playing through the zoomed waveform keeps that phrase selected. Choose another row explicitly to edit it. Turn Zoom line off to resume sequential marking and automatic following.
- Timing edits preserve the opposite boundary, scale syllable/keyframe times and support undo/redo. Invalid boundaries are rejected.
- The project now uses the MIT license. Dependencies keep their own licenses.

### Windows x64 downloads

- **Portable ZIP:** extract the entire archive and run `LyricCandle/LyricCandle.exe`. Keep `_internal` alongside the executable. Settings live in its `data` folder. Python is not required.
- **Setup EXE:** installs for your Windows user, with English/Spanish setup, Start menu shortcut, optional desktop shortcut and an uninstaller. Settings use your application data folder; uninstalling does not delete projects or user settings. Python is not required.
- `.sha256` files let you verify each download with `Get-FileHash -Algorithm SHA256 <file>`.

Windows 10/11 x64. These builds are unsigned, so Windows may show an unknown-publisher notice. External `ffmpeg.exe` and `ffprobe.exe` remain necessary for export, waveforms and video probing; place them in `tools` beside the EXE or add them to PATH. They are not included. This is still an alpha; sung-lyric recognition and automatic vocal alignment are not implemented.

Both operating-system test jobs must pass before release. Package checks launch the extracted portable app, install silently, launch the installed app and uninstall it. Audible playback and all hardware/codec combinations require testing on your own machine.

## Español

**Hotfix: marcar límites con Zoom frase ahora modifica la frase seleccionada.**

- Con Zoom frase activo, Marcar inicio (Ctrl+M) cambia solo el inicio de la frase seleccionada; Marcar final (Ctrl+F), solo su final. No avanza de fila ni cierra otra frase.
- Buscar o reproducir en la onda ampliada conserva esa selección. Selecciona otra fila para editarla. Desactiva Zoom frase para recuperar el marcado secuencial y el seguimiento automático.
- Se conserva el límite opuesto, se reajustan tiempos de sílabas/keyframes y funciona deshacer/rehacer. Los límites inválidos se rechazan.
- El código del proyecto adopta la licencia MIT. Las dependencias mantienen sus propias licencias.

### Descargas para Windows x64

- **ZIP portable:** extrae todo y abre `LyricCandle/LyricCandle.exe`. Conserva `_internal` junto al ejecutable. Los ajustes quedan en su carpeta `data`. No necesitas Python.
- **EXE instalador:** instala para tu usuario, incluye español/inglés, acceso en Inicio, acceso opcional en escritorio y desinstalador. Los ajustes usan la carpeta de datos del usuario; desinstalar no elimina proyectos ni ajustes. No necesitas Python.
- Los archivos `.sha256` permiten comprobar cada descarga con `Get-FileHash -Algorithm SHA256 <archivo>`.

Windows 10/11 x64. Los compilados no están firmados y Windows puede mostrar un aviso de editor desconocido. Para exportar, generar la onda y analizar video necesitas `ffmpeg.exe` y `ffprobe.exe` externos: ponlos en `tools` junto al EXE o agrégalos al PATH. No vienen incluidos. Sigue siendo una alpha; aún no reconoce letras cantadas ni alinea voces automáticamente.

La publicación exige que pasen las pruebas en ambos sistemas. La comprobación de paquetes abre el portable extraído, instala en silencio, abre la aplicación instalada y la desinstala. La reproducción audible y todas las combinaciones de hardware/códecs deben probarse en tu equipo.
